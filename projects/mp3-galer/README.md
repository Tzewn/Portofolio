# mp3 Galer

Web app konverter YouTube ke MP3 dengan tampilan hijau-hitam-biru.

## Fitur

- Tempel link YouTube (termasuk Shorts, youtu.be, dan music.youtube.com)
- Pilihan kualitas 128–320 kbps
- Pemutar audio di halaman, tombol unduh, dan riwayat yang bisa dihapus
- Batas durasi video 30 menit, proses konversi sekitar 1 menit

## Teknologi

TypeScript, server-backed (konversi berjalan di server).

Kode aplikasi tidak dicerminkan di repo portofolio ini; halaman ini adalah ringkasan proyeknya.
